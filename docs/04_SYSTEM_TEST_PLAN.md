## 1. 测试概述

### 1.1 测试类型
| 测试类型 | 覆盖范围 | 说明 |
|---------|---------|------|
| 功能测试 | 所有需求 | 验证软硬件功能符合SRS |

| 性能测试 | 响应时间/并发 | WebSocket延迟、API吞吐 |

| 兼容性测试 | 多浏览器/多设备 | Chrome/Firefox/Safari/Edge |

## 2. 系统测试用例

### 2.1 功能测试

#### FT-1: 传感器数据采集
| 用例ID | 描述 | 操作步骤 | 预期结果 |

## 4. 性能测试

### 4.1 性能指标
| 指标 | 目标 | 测试方法 |
|------|------|---------|
| WebSocket延迟 | P95 ≤ 500ms | 1000次ping-pong测量 |
| API响应时间 | P95 ≤ 200ms | JMeter/Locust 100并发 |
| 历史查询(1000条) | ≤ 1s | SQLite EXPLAIN QUERY PLAN |
| 内存占用(服务器) | ≤ 256MB | psutil监控 |
| 固件RAM占用 | ≤ 200KB | linker map分析 |
| 本地屏刷新率 | ≥ 1Hz | 示波器/GPIO翻转测 |

### 4.2 压力测试
| 场景 | 持续时间 | 验证点 |
|------|---------|--------|
| 72h连续运行 | 72h | 无内存泄漏，无重启 |
| 1000次启停循环 | 1000次 | 状态机无异常 |
| 4G反复断连 | 50次断连 | 自动重连正常 |
| Web 50并发 | 10分钟 | 无连接丢失 |
