## Excel 甘特图生成说明

运行以下命令自动生成 Excel 可视化甘特图：

```bash
pip install openpyxl
python generate_gantt.py
```

Excel文件包含:
- **Sheet1 "甘特图"**: 条形图视图的任务分解
- **Sheet2 "里程碑"**: 关键节点汇总表
- **Sheet3 "资源分配"**: 人力投入估算
