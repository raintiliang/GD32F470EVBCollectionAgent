## 1. 项目概述

### 1.1 项目名称
**材料加速老化测试系统**（Material Accelerated Aging Test System，以下简称 MAATS）

### 1.2 项目背景
客户需要一台材料加速老化测试设备，用于在受控的二氧化碳浓度和湿度环境下对材料样品进行持续反应测试。设备需同时支持本地显示控制和远程Web监控。

### 1.3 硬件系统架构

## 2. 硬件规格需求

### 2.1 主控单元
| 项目 | 规格 | 备注 |
|------|------|------|
| MCU/SoC | ARM Cortex-M4/M7 或 RISC-V | 建议 STM32H743 / T113-S3 / ESP32-S3 |
| 主频 | ≥ 180 MHz | 支持 FreeRTOS 多任务 |
| RAM | ≥ 512 KB | 采集缓冲 + FATFS |
| Flash | ≥ 2 MB | 程序存储 |
| 通信接口 | UART×3, I2C×1, SPI×1, GPIO×8, RS485×1 | 见下方详情 |

### 2.2 传感器

#### CO2 浓度传感器
| 项目 | 规格 |
|------|------|
| 型号 | Sensirion S8-005 或 MG-811（备选） |
| 通信接口 | UART (9600bps, 8N1) |
| 测量范围 | 400 ~ 5000 ppm (S8-005) |
| 精度 | ±(50ppm + 3%MV) |
| 预热时间 | ≤ 10s |
| 输出协议 | Modbus-Like 或 主动输出字符串 |

#### 温湿度传感器
| 项目 | 规格 |
|------|------|
| 型号 | AHT10 / SHT40 |
| 通信接口 | I2C (100kHz / 400kHz) |
| 温度范围 | -40 ~ 85°C, ±0.3°C |
| 湿度范围 | 0 ~ 100%RH, ±2%RH |
| 采样周期 | ≥ 1s |

### 2.3 执行器

| 设备 | 接口 | 控制逻辑 |
|------|------|---------|
| 电磁阀 (CO2) | GPIO (推挽输出, 3.3V/5V) | 高电平=开启充气, 低电平=关闭 |
| 加湿机 | GPIO (推挽输出) | 高电平=开启加湿, 低电平=关闭 |
| 除湿机模组 | RS485 | Modbus RTU, 9600bps, 地址可配置 |

### 2.4 通信模块

#### 4G模块
| 项目 | 规格 |
|------|------|
| 模块型号 | SIM7600 / SIM7020 / ESP32-C3 (Cat.1) |
| 通信协议 | MQTT (publish: sensor data, subscribe: control commands) |
| 服务器地址 | 可配置 (IP:PORT 或域名) |
| 心跳间隔 | 30s |

#### TF存储卡
| 项目 | 规格 |
|------|------|
| 容量 | ≥ 16GB Class10 |
| 文件系统 | FAT32 |
| 数据格式 | CSV (每行: timestamp, CO2, Temp, Humid, State) |
| 存储周期 | ≥ 30天 (1次/分钟 ≈ 43,200条) |
| 滚动覆盖 | 保留最新N个文件，超出删除最旧 |

### 2.5 本地显示与输入
| 项目 | 规格 |
|------|------|
| 屏幕 | 5寸 TFT RGB 480×272 或 800×480, SPI/RGB接口 |
| 显示内容 | 温度/湿度/CO2浓度, 反应持续时间, 当前状态 |
| 按键 | 4~6个 (设置/确认/上/下/启动/停止) |
| 屏幕更新频率 | ≥ 1Hz |

### 3.3 设备端固件

#### 3.3.1 任务划分 (FreeRTOS)
| 任务名 | 优先级 | 周期 | 说明 |
|--------|--------|------|------|
| SensorTask | 3 | 1s | CO2 (UART轮询) + 温湿度 (I2C) |
| ActuatorTask | 2 | 500ms | 电磁阀/加湿GPIO + 除湿RS485 |
| StorageTask | 4 | 60s | CSV写TF卡 |
| CommTask | 2 | 5s | 4G模块 MQTT publish |
| DisplayTask | 5 | 1s | 屏幕刷新 |
| KeyScanTask | 5 | 100ms | 按键扫描 + 消抖 |
| ControlTask | 1 | 200ms | 闭环控制 (PID) |

#### 3.3.2 控制逻辑
- **CO2控制**: 目标浓度 vs 当前浓度 → PID调节电磁阀开/关
- **湿度控制**: 目标湿度 vs 当前湿度 → PID调节加湿/除湿（互锁，不可同时）
- **安全联锁**: 湿度>90%RH 时自动关闭加湿；CO2>5500ppm 时报警并关闭电磁阀

### 3.4 服务器端 (Backend)

#### 3.4.1 技术栈
| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 框架 | **FastAPI** | 异步API + 自动Swagger文档 |

| 文件存储 | 本地文件系统 | TF卡数据镜像 |

#### 3.4.2 API 端点
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/login | 账户登录，返回JWT |
| GET | /api/auth/me | 获取当前用户信息 |

| GET | /api/current | 获取当前传感器值+设备状态 |

## 4. 通信协议

### 4.1 MQTT 主题设计
| 主题 | 方向 | 内容 |
|------|------|------|
| `maats/{device_id}/telemetry` | 设备→服务器 | `{co2, temp, humid, timestamp, state}` |
| `maats/{device_id}/control` | 服务器→设备 | `{cmd: "start"\|"pause"\|"stop"\|"resume", params}` |
| `maats/{device_id}/setpoint` | 服务器→设备 | `{co2_sp, humid_sp}` |
| `maats/{device_id}/ack` | 设备→服务器 | `{cmd, result, message}` |

### 4.2 TF卡数据格式 (CSV)
```csv
timestamp,co2_ppm,temperature_c,humidity_rh,state,co2_valve,humidifier,dehumidifier
2026-09-18T10:00:00,850,25.3,65.2,REACTING,1,0,0
2026-09-18T10:01:00,862,25.4,65.1,REACTING,1,0,0
```

## 5. 非功能性需求

| 类别 | 需求 |
|------|------|
| 可靠性 | 设备连续运行 ≥ 72小时无重启；4G断线自动重连 (间隔: 30s/60s/120s 退避) |
| 实时性 | Web端数据延迟 ≤ 5s（4G网络）；本地显示延迟 ≤ 2s |
| 安全性 | 所有API强制HTTPS；JWT secret ≥ 256bit；密码bcrypt hash |
| 容量 | 单台设备支持 ≥ 10000 条历史记录查询 (分页) |
| 兼容性 | Chrome/Edge/Firefox/Safari (PC+Mobile) |
