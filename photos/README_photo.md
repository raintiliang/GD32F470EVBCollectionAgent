# 照片整理工具 (Photo Organizer)

这是一个基于 Python 的照片整理工具，旨在帮助你根据拍摄日期自动归档海量照片，并清理重复项。

## 功能特性

1.  **支持压缩包**：自动解压并整理压缩包中的照片。支持 `.zip`, `.tar.gz`, `.tar`, `.rar` 等格式。
2.  **流式/分批处理**：针对大文件量，压缩包会逐个在临时目录解压，处理完成后立即清理，节省磁盘空间。
3.  **按日期归档**：读取图片 EXIF 信息中的拍摄日期，自动创建 `年/月/日` 层级的文件夹。
4.  **重复识别**：通过文件的 MD5 哈希值识别内容完全相同的图片，避免重复归档。
5.  **支持 EXIF 回退**：如果图片没有 EXIF 信息，将使用文件的修改日期。
6.  **操作安全**：默认使用“复制”模式；也支持“移动”模式。
7.  **详细报告**：整理结束后生成 JSON 和 CSV 格式的报告。

## 安装依赖

脚本依赖 `Pillow` 库来读取图片 EXIF 信息。处理 `.rar` 文件需要 `rarfile` 库。

```bash
pip install Pillow rarfile
```
> 注：处理 `.rar` 还需要系统安装有 `unrar` 工具。

## 使用说明

脚本通过命令行运行，需要指定**源路径**（文件夹或压缩包）和**目标路径**。

### 基本命令 (整理文件夹)

```bash
python photo_organizer.py "D:/我的图片/待整理" "D:/我的图片/归档完成"
```

### 处理压缩包

可以直接指定一个压缩包文件：

```bash
python photo_organizer.py "E:/备份/2023照片.zip" "D:/Photo_Archive"
```

或者指定一个包含多个压缩包的文件夹，脚本会递归遍历并逐个处理。

### 移动模式 (整理后删除原文件)

```bash
python photo_organizer.py "C:/Users/User/Pictures" "D:/Photo_Archive" --action move
```

### 参数说明

*   `source`: 存放照片的文件夹或单个压缩包文件。
*   `target`: 整理后照片存放的根目录。
*   `--action`: 可选 `copy` (默认) 或 `move`。

## 输出报告

整理完成后，在**目标文件夹**下会生成：
*   `organize_report.json`: 包含每张照片处理状态、日期和路径的详细记录。
*   `organize_summary.csv`: 处理总数、重复项统计的简要汇总。

## 注意事项

*   支持的图片格式：`.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.tiff`, `.webp`。
*   对于同名但内容不同的照片，脚本会自动重命名以防覆盖。
